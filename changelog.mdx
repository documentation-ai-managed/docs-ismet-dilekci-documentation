## Release History

<Update label="2024-10-15" description="v2.1.0" tags={["feature", "improvement"]}>

## New Features

- Added real-time collaboration features for team editing
- Introduced dark mode support across all interfaces
- Implemented advanced search with filters and operators
- Added support for custom domains and SSL certificates

## Improvements

- Enhanced API performance with 40% faster response times
- Improved mobile responsiveness for all documentation pages
- Updated user interface with modern design patterns
- Added comprehensive error messages and validation

</Update>

<Update label="2024-09-20" description="v2.0.0" tags={["breaking", "feature"]}>

## New Features

- Complete platform redesign with new navigation system
- Introduced API versioning and backward compatibility
- Added webhook support for external integrations
- Implemented role-based access control

## Breaking Changes

- API endpoints now require version prefix (e.g., `/v2/projects`)
- Authentication now uses Bearer tokens instead of API keys
- Deprecated old webhook format - migrate to new payload structure

</Update>

<Update label="2024-08-10" description="v1.5.0" tags={["feature", "bugfix"]}>

## New Features

- Added support for multiple file formats including PDF and DOCX
- Introduced template system for consistent documentation
- Added bulk import/export functionality
- Implemented usage analytics and reporting

## Bug Fixes

- Fixed issue with large file uploads timing out
- Resolved search indexing problems with special characters
- Corrected permission inheritance in nested folders
- Fixed mobile layout issues on iOS devices

</Update>
