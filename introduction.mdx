## Key Features

Our documentation platform includes advanced features designed for modern development teams. From version control to search capabilities, we provide everything you need to maintain high-quality documentation.

<Tabs>
  <Tab title="Version Control" icon="git-branch">
    Track changes and collaborate effectively with built-in version history.
    
    <Steps>
      <Step title="Create Repository" icon="plus">
        Set up a new documentation repository for your project.
        ````bash
        curl -X POST https://api.ismetdocs.com/v1/repositories \
          -H "Authorization: Bearer YOUR_API_KEY" \
          -H "Content-Type: application/json" \
          -d '{"name": "my-project-docs", "description": "Documentation for my project"}'
        ````
      </Step>
      <Step title="Add Content" icon="file-text">
        Upload your markdown files and organize them into sections.
