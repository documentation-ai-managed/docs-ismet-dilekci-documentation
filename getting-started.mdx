## Quick Setup

Getting started with Ismet Dilekci Documentation is straightforward. Follow these steps to have your documentation space up and running in under 10 minutes.

<Steps>
  <Step title="Sign Up" icon="user">
    Create your free account at docs.ismetdilekci.com.
    
    <CodeGroup tabs="cURL,Bash">
      ```bash
curl -X POST https://api.ismetdocs.com/v1/auth/signup \
  -H "Content-Type: application/json" \
  -d '{"email": "your@email.com", "password": "securepassword123"}'
```
      ```bash
echo '{"email": "your@email.com", "password": "securepassword123"}' | \
  curl -X POST https://api.ismetdocs.com/v1/auth/signup \
    -H "Content-Type: application/json" \
    -d @-
```
    </CodeGroup>
  </Step>
  <Step title="Create Workspace" icon="folder">
    Set up your first workspace and invite team members.
  </Step>
  <Step title="Import Content" icon="upload">
    Upload existing documentation or start fresh with our templates.
  </Step>
  <Step title="Customize" icon="settings">
    Configure branding, permissions, and integrations.
  </Step>
</Steps>

<Callout kind="info">
  Need help? Our support team is available 24/7 via chat or email.
</Callout>
